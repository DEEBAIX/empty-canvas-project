# منصة Leads API — الخطة الأساسية

## الجواب المختصر
نعم، المنصة ممكنة بالكامل. لكن نقطة واحدة يجب تصحيحها من البداية:
ملف Excel بحجم 2–10 جيجا لا يُرفع ولا يُقرأ كملف. الحل الصحيح هو **تحويل الملف إلى صفوف داخل قاعدة بيانات** عند الرفع، وبعدها الـ API يقرأ من قاعدة البيانات (سريع جداً، فلترة، صفحات) بدل نقل ملفات.

## المرحلة 1 — نبنيها الآن على Lovable Cloud
Lovable Cloud هو Postgres كامل. نبني كل شيء عليه، وبعدها ننقله إلى VPS الخاص بك (خطة الترحيل في الأسفل).

### 1. Landing page (صفحة واحدة)
تعريف بسيط بالخدمة + زر دخول للأدمن. بدون تسجيل مستخدمين.

### 2. تسجيل دخول الأدمن
حساب واحد فقط (أنت). كل ما بعده محمي.

### 3. لوحة التحكم — قسم الرفع (Import)
- اختيار الدولة (Country) + اسم مجموعة (Dataset / batch)
- رفع الملف: **CSV مفضّل** (يمكن رفع Excel صغير مباشرة؛ الملفات الضخمة تُحوَّل إلى CSV أولاً)
- الرفع يتم **على أجزاء (chunked)** ثم معالجة تدريجية: قراءة سطر سطر → إدخال دفعات 5000 صف
- شريط تقدّم + حالة (pending / processing / done / failed) + عدد الصفوف + عدد المكرر المستبعد
- ربط الأعمدة (column mapping): تحديد أي عمود هو الاسم/الهاتف/الإيميل/المدينة… مرة واحدة لكل شكل ملف
- إزالة التكرار تلقائياً حسب (الهاتف أو الإيميل + الدولة)

### 4. لوحة التحكم — قسم البيانات
- تصفح/بحث/فلترة حسب الدولة والمجموعة
- عدادات: كم Lead لكل دولة، كم Dataset، آخر تحديث
- حذف مجموعة كاملة

### 5. لوحة التحكم — قسم API Keys
- إنشاء مفتاح لكل منصة خارجية (اسم المنصة + وصف)
- **صلاحيات دقيقة**: تحديد الدول و/أو المجموعات المسموح بها لهذا المفتاح فقط
- حد استهلاك (rate limit) + تاريخ انتهاء اختياري
- تفعيل/إيقاف/حذف المفتاح فوراً
- المفتاح يُعرض **مرة واحدة فقط** عند الإنشاء (يُخزَّن مُشفّراً hash)

### 6. لوحة التحكم — الاستخدام والسجلات
- عدد الطلبات لكل مفتاح، آخر استخدام، عدد الصفوف المسحوبة، الأخطاء
- سجل عمليات (من رفع ماذا ومتى، من أنشأ/ألغى مفتاح)

### 7. الـ Public API (للمنصات الأخرى)
نقاط عامة محمية بالمفتاح في الهيدر `Authorization: Bearer <key>`:
- `GET /api/public/v1/leads?country=KW&dataset=...&page=1&limit=1000&updated_since=...`
- `GET /api/public/v1/leads/count`
- `GET /api/public/v1/countries` (فقط ما يسمح به المفتاح)
- ردود JSON مع pagination (cursor) — لا يوجد نقل ملفات إطلاقاً، فقط البيانات المطلوبة
- كل طلب: تحقق من المفتاح → تحقق من صلاحية الدولة → تسجيل الاستخدام

## الأمان
- المفاتيح مخزّنة hash (SHA-256) لا نص صريح
- كل استعلام API مُقيَّد إجبارياً بالدول المسموحة للمفتاح على مستوى قاعدة البيانات
- RLS مفعّل على كل الجداول؛ لا وصول عام مباشر لقاعدة البيانات
- Rate limiting + إمكانية إلغاء أي مفتاح لحظياً
- سجل تدقيق كامل

## قاعدة البيانات (الجداول)
```text
countries        رمز الدولة + الاسم
datasets         مجموعة رفع: دولة، اسم، حالة، عدد الصفوف
leads            الصف نفسه: dataset_id, country, name, phone, email,
                 city, company, extra (JSONB للأعمدة الإضافية)
                 فهارس على (country), (dataset_id), (phone), (email)
api_keys         الاسم، hash المفتاح، حالة، حد الطلبات، تاريخ الانتهاء
api_key_scopes   ربط المفتاح بالدول/المجموعات المسموحة
api_usage_logs   طلبات، مفتاح، وقت، عدد صفوف، status
```
`extra JSONB` مهم: كل ملف Excel أعمدته مختلفة، وهذا يستوعب أي عمود إضافي بدون تعديل الجداول.

## الانتقال إلى VPS لاحقاً
نصيحتي: ابنِ الآن على Lovable Cloud، والترحيل لاحقاً سهل لأن كل شيء Postgres قياسي:
1. على الـ VPS: تثبيت PostgreSQL (أو Supabase self-hosted لتحصل على نفس الواجهة تماماً — الأسهل)
2. `pg_dump` من Cloud → `pg_restore` على الـ VPS
3. تغيير متغيّرات الاتصال في المشروع فقط، الكود يبقى كما هو
4. للملفات الأصلية (نسخ احتياطية من ملفات Excel) — تُخزَّن على الـ VPS في مجلد أو MinIO؛ لكن الـ API لا يعتمد عليها، يعتمد على الجداول

مواصفات VPS مقترحة للبداية: 4 vCPU / 16GB RAM / 200GB NVMe SSD.

## ما كان ناقصاً في فكرتك (نصائح)
1. **الملف ليس وحدة التخزين** — الصفوف هي. هذا يحل مشكلة الـ 10 جيجا كلياً.
2. **إزالة التكرار** ضرورية: نفس الرقم سيتكرر بين الملفات.
3. **تنظيف وتوحيد الأرقام** (صيغة دولية +965…) وإلا الفلترة والدمج لن يعملا.
4. **Rate limit وسجل استخدام** حماية من تسريب مفتاح.
5. **دعم `updated_since`** ليسحب العميل الجديد فقط بدل كل البيانات.
6. **Datasets قابلة للحذف/الاستبدال** بدل خلط كل شيء في جدول واحد بلا تتبع.
7. تحويل Excel الضخم إلى CSV قبل الرفع (أسرع بعشرات المرات وأخف بكثير).
